# 🏠 PropDoc

**PropDoc** is a web-based property management system designed to streamline the management of properties, services, and maintenance records. Built with HTML, CSS, and JavaScript, it offers an intuitive interface for property owners, service providers, and administrators.

## 🚀 Features

- **User Authentication**: Secure login and signup functionalities.
- **Property Management**: Add, view, and manage property listings.
- **Service Management**: Manage services offered, including adding and updating service details.
- **Service Records**: Maintain records of services rendered to properties.
- **Job Tracking**: Monitor ongoing and completed jobs.
- **User Profiles**: View and edit user information.
- **Responsive Design**: Optimized for various devices and screen sizes.
